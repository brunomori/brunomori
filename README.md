## Current project — SRE Platform Lab

**Status: planning and development**

A local Kubernetes learning environment designed to explore platform engineering and reliability practices.

Planned scope:

- Highly available Kubernetes control plane
- Infrastructure provisioning and configuration automation
- CI/CD and GitOps
- Metrics, logs, dashboards and alerting
- Troubleshooting, recovery exercises and runbooks

## Learning principles

- Build reproducible labs and document the results.
- Understand failure modes, not just successful deployments.
- Automate repetitive tasks and review changes before applying them.
- Keep credentials and real environment data out of public repositories.
